BUILD THE APK (no laptop needed)
1. Create a free account at github.com and make a new repository.
2. Upload ALL files from this folder (keep the .github folder).
3. Open the Actions tab, wait for "Build APK" to finish (about 3-5 min).
4. Open the finished run, download the YedhuPortfolio-apk artifact, unzip it, install app-debug.apk on your phone.
   (Allow "install from unknown sources" when Android asks.)

Or open this folder in Android Studio and choose Build > Build APK(s).
Edit the site in app/src/main/assets/index.html.
